# 🌦️ RRFS Meteorologia

**RRFS Meteorologia** é um sistema de **previsão do tempo** que também detecta **tempestades** e outros eventos climáticos severos.

Ele combina **8 modelos climáticos** e usa **inteligência artificial** para melhorar a taxa de acerto das previsões.

---

## 🧠 Como funciona

### Conjunto de modelos (ensemble)

O sistema usa **8 modelos climáticos** ao mesmo tempo e forma um **conjunto** (ensemble) com os resultados. Em vez de confiar em apenas um modelo, ele analisa todos juntos para prever como estará o clima.

### Aprendizado e ajuste de pesos

O sistema **aprende com cada variável** (temperatura, chuva, vento, pressão etc.) e **ajusta os pesos** dados a cada modelo.

- Os modelos que **acertam mais** em determinada variável ganham **mais peso**.
- Os modelos que **erram mais** ganham **menos peso**.
- O objetivo é **aumentar a taxa de acerto** das previsões de cada variável.

### Análise e verificação

Com o conjunto formado, o sistema **analisa e verifica** como o clima deve se comportar na previsão e **detecta tempestades** e outros eventos severos.
